# acasolino.com – WordPress

Codice personalizzato del sito WordPress con Bricks.

- `mu-plugins/acasolino-progetti.php`: tipo di contenuto Progetti (`/progetti/`, `/progetto/<slug>/`), tassonomia Tipologia e scheda progetto (cliente, anno, ruolo, link, in evidenza).
- `scripts/setup.sh`: configurazione iniziale di un'installazione pulita con WP-CLI (lingua, permalink, Rank Math, pagine base).
